# 风铃森林 · Windbell Woods

原创、可运行的第三人称 3D 森林探索小游戏。小狐狸在山谷收集浆果，帮助小刺猬小栗，找齐三枚风铃，回到古树完成旅程。没有生命惩罚和倒计时。

## 运行

需要 Node.js 22.12+（已在 Node 24 验证）。

```sh
npm ci
npm run dev
```

浏览器打开终端显示的开发服务器地址。生产构建：`npm run build`；查看构建：`npm run preview`。部署时发布 `dist/`，无需后端、API 密钥或在线素材服务。

## 操作

- WASD / 方向键移动，Shift 加速。
- 空格跳跃；下落时长按空格滑翔。
- 鼠标或触摸拖动旋转镜头，滚轮缩放。
- E 与小栗、古树互动；Esc 暂停。
- 手机提供方向、跳跃和互动触摸按钮。
- 进度保存在浏览器 localStorage。清除站点存储可重新开始。

## 已实现

原创 Blender 狐狸 GLB 模型、程序驱动的步态与尾巴动画、连续起伏地形、森林小路、蘑菇小屋、池塘木桥、山顶石环、蘑菇花园、古树；跳跃与滑翔、树干碰撞、落水安全重生、12 颗浆果、居民对话任务、3 枚风铃、通关画面、自动存档、位置小地图和合成音效。

这是范围完整的小型首版，尚不是商业成品。当前没有骨骼动画资产、配乐、复杂物理交互或专业设备兼容性认证。地面采用高度场角色控制；浅池塘是可穿行的装饰区域。

## 验证

启动开发服务器后运行 `npm test`。测试使用 Playwright 和系统 `/usr/bin/chromium`；其他系统可设置 `CHROMIUM_PATH`。覆盖加载、实际键盘移动、跳跃、滑翔、对话、收集、任务奖励、结尾、落水、存档、暂停，并保存桌面和手机截图至忽略目录 `artifacts/`。测试 URL 的 `?test` 仅开启测试用状态与传送接口，普通访问不暴露该接口。测试用传送用于遍历任务状态，不代表所有路线都已由自动寻路验证。

## 美术与源码

美术方向：暖橙、鼠尾草绿、奶油黄的柔和绘本森林。设计参考《A Short Hike》的轻松探索、《Lil Gator Game》的柔和卡通色彩，未使用这些作品的资产。当前环境对 B 站及参考网站的访问被拒绝，未下载或复制其内容。

模型和场景均为本项目原创生成。`scripts/make_fox.py` 是可复现的 Blender 模型源：在仓库目录执行 `blender -b --python scripts/make_fox.py` 生成 `public/models/fox.glb`。运行游戏不需要安装 Blender。

技术：TypeScript、Three.js、Vite。`src/main.ts` 负责游戏循环和任务，`src/world.ts` 负责地形与场景，`src/style.css` 负责界面。
